# TP Final — Informática I

**Torneo Clandestino**: un juego de lucha y decisiones hecho en Java. Entrás a un ring clandestino y tenés que salir Victorioso contra Takeshi "La Montaña". Podés pelear, convencerlo, sobornarlo o darle un onigiri.

Tiene dos versiones:

- **FinalCLI**: versión de consola por turnos, en Java puro.
- **FinalJavaFX**: versión gráfica en tiempo real, con JavaFX 21 y Maven.
